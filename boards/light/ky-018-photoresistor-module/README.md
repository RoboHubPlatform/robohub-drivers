# ky-018-photoresistor eval board

A KY-018 photoresistor on an ADC channel.

## Pinout

| Pin | Carries |
|-----|---------|
| vcc | power |
| gnd | ground |
| ao | analog_in |

## Driver

`robohub-driver-photoresistor-adc` — see `drivers/light/photoresistor-adc`. Selecting `RH_BOARD_KY_018_PHOTORESISTOR_MODULE` brings it in.
